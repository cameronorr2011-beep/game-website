2 · Connect the player phone (Wi-Fi ADB)
  1. On the phone open Settings → About phone and tap Build number 7× to unlock Developer options.
  2. Open Settings → Developer options and switch ON Wireless debugging (phone must be on the SAME Wi-Fi as this PC for the one-time pairing).
  3. Tap Wireless debugging → Pair device with pairing code. A 6-digit code and IP:PORT appear.
  4. Type that pair IP:PORT and code below, then Pair.
  5. Then tap Wireless debugging again to see its connect IP:PORT and enter it below, then Connect.
  6. Keep the phone screen on while playing: Settings → Display → Screen timeout 10 min.
