NeuroML

A computational-neuroscience testbed that learns a real game the way brains are thought to: perception → prediction → decision → plastic feedback. It plays Clash Royale on the phone — either from inside the phone itself or from your PC over Wi-Fi. No API keys are ever required — the AI coach runs through NeuroML's own hosted endpoint.

NERD PATH · PC + PHONE

🖥️ Windows desktop app

A real installed app (not a browser tab). On first run it sets up Python + torch itself, then walks you through the Wi-Fi developer pairing to link to the phone that plays the game.

  • The wizard shows every step: unlock Developer options (7× Build number), enable Wireless debugging, Pair device with pairing code, then connect
  • It reads the phone's real resolution automatically and writes the config
  • The app window becomes the live dashboard: phone view, micro-dot neuron layers, coach feed, win/loss record — showing the connected player's account
  • Remote (different Wi-Fi / mobile data): pair once, then use Tailscale (100.x.y.z) or router port-forward 5555
Download NeuroML-Windows-Setup.exe …or the portable .exe (no install)

The pretrained brain

Both apps fetch it automatically when one is published on the Releases page (fetch_brain.py / first launch). If none is published you start with a fresh brain that learns live from its first match — nothing is faked. Existing training files are never overwritten.

ml_policy.ptDQN policy + target weights — ~100 MB total (13.7 M params fp32, two networks)
spiking_brain.jsonLIF/STDP nucleus + affect state — a few MB

Replay memory (ml_replay.json, up to 60 000 episodes) is personal training experience and is not shared. Federated learning stays opt-in and anonymized: packages carry only policy/target weights and stats — no account, no screenshots, no keys.

Do I need a Groq API key?

No. The AI mentor (end-of-match critiques, deck suggestions) is routed through NeuroML's own endpoint, which holds the key server-side. You download, install, launch — the coach just works. A local groq_key.txt still works too, for power users who prefer direct calls.

Honest limitations

Vision is pixel-scanning + statistics, not object detection. Internal “valence” channels are computational reward signals, not claims of sentience. The world model is a scored 1-tick baseline, still accumulating ablation data. On-phone training is slower than desktop — same brain, mobile CPU.

NeuroML — measured, not claimed. Everything it learns stays on your device.
