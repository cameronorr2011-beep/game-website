NeuroML

A computational-neuroscience testbed that learns a real game the way brains are thought to: perception → prediction → decision → plastic feedback. It plays Clash Royale on a connected Android phone, from any PC.

Download

The app (code) is a small ~50 KB zip containing launchers, the brain and the dashboard. install.bat fetches Python + torch so you don't have to.

Download NeuroMLCR.zip (app) Source on GitHub

The pretrained brain is a separate ~52 MB file (ml_policy.pt — the trained DQN weights), plus replay memory that can grow to hundreds of MB or more. It's not inside the small zip.

Train it yourself from scratch: fresh installs learn live and write ml_policy.pt + ml_replay.json to their own folder within minutes. To publish instead, see “Publish the pretrained brain” in the README.

If the zip won't extract

Windows Explorer sometimes blocks freshly-downloaded zips. In order of votes:

  1. Make sure the file finished downloading (~50 KB check size) — then right-click it → Extract All… (don't use “Open with Navigate into”).
  2. Or extract in Terminal/PowerShell, which does not consult Chromium's quarantine: tar -xf NeuroMLCR.zip
  3. Extracted .bat files: if Windows Defender marks them “unknown publisher”, right-click → Properties → tick Unblock, and confirm before running.

Setup (5 steps)

  1. Unzip the download and double-click install.bat — checks Python, installs torch + tools, downloads adb if missing. If Python is missing it opens the download page for you (check “Add Python to PATH”, then rerun).
  2. Put your groq_key.txt (one line, starts with gsk_) in the folder.
  3. Double-click connect_phone.bat and follow the pairing prompts (same Wi-Fi, or Tailscale/ZeroTier/ port-forward for remote).
  4. Double-click NeuroMLCR.bat — the AI Coach dashboard opens in your browser at http://127.0.0.1:8765 (live phone view + loss curves + coach feed) and the brain starts playing matches.
  5. Updates never wipe memory: updater.py replaces code, never data.
Fair play: automating Clash Royale violates Supercell’s ToS. Use an account you accept losing. The app never force-relaunches the game and only taps inside it.

Honest limitations

Vision is pixel-scanning + statistics, not object detection. Internal “valence” channels are computational reward signals, not claims of sentience. The world model is a scored 1-tick baseline, still accumulating ablation data.

NeuroML — measured, not claimed. Everything it learns stays on your disk.
